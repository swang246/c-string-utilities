# c-string-utilities
A C programming project implementing utility functions for number-base conversion, vowel counting, word-order reversal, and Caesar cipher character rotation.

Features

1. Number Base Conversion
   
      Converts unsigned integers into string representations in bases 2 through 36, using digits 0–9 and letters A–Z.

3. Vowel Counter
   
      Counts occurrences of the five English vowels in a string, supporting both uppercase and lowercase letters.

5. Word Reversal
   
      Reverses the order of words in a string while preserving the characters within each word.

7. Caesar Cipher
   
      Shifts alphabetic characters by a specified displacement, wrapping around the alphabet while preserving spaces and punctuation.
